📘 User Documentation

Use this guide to log consistent training sessions and share clean summaries.

Getting started

  • Sign in with an email that has an assigned dog.
  • Select a dog from the Select Dog card before creating entries.
  • If no dog appears, contact your admin for an assignment.

Create a training entry

  • Capture location or type a location name manually.
  • Select required fields: Location Type and Overall Behavior.
  • Set duration, choose distractions and commands, and add short notes.
  • Use Save Entry to sync data to Firestore.

Review history and reports

  • Use Start Date and End Date filters in History to control the report period.
  • Use Copy Summary for biweekly report text.
  • Use Export Entries (CSV) for spreadsheet reporting.

Profile and account

  • Set your name, handler name, and organization in Settings.
  • Change your password from the Change Password card.
  • If login fails after account creation, verify your admin assignment.
🛠️ Admin Documentation

Use this guide for onboarding trainers, assigning dogs, and exporting complete records.

Access and permissions

  • The Admin Guide is opened from the top-right Open Admin Guide header button.
  • Only users with role admin in users can access the Admin tab.
  • Each trainer must have at least one dog_assignments record before signup/login is allowed.
  • Unauthorized authenticated users are automatically signed out.

Firebase Console: promote user to admin

  • Open Firebase Console for puppy-tracker-c630b and go to Firestore Data.
  • Open collection users, then open the user document by UID.
  • Set field role to admin (string), then save.
  • Have the user log out and back in so role checks refresh in the app.

Litter management workflow

  • Add mother name, litter name, and one or more dog names.
  • Dogs are stored in dogs and become assignable immediately.
  • Use the Registered Dogs section to confirm roster coverage.
  • Enter a litter completely when possible; partial litter entry usually requires follow-up edits in Firebase.

Firebase Console: add or correct dogs in a litter

  • To add missing dogs, use the app if possible; otherwise add a new document in dogs.
  • Dog document ID is generated from normalized dog name, so spelling corrections usually need a new document.
  • For spelling fixes: create a corrected dogs doc, update affected dog_assignments and entries.dogName, then remove the incorrect dog doc.
  • Keep dogName, motherName, and litterName consistent across records for reporting accuracy.

Trainer assignment workflow

  • Assign a registered dog to a trainer email in Assign Dog to Trainer.
  • Use normalized lowercase trainer emails to avoid duplicates.
  • Remove assignments when dogs are reassigned or trainers roll off.

Trainer deactivation workflow

  • Use the combined User Management rows to change role and deactivate/reactivate in one place.
  • Use the filter above the rows: Active only (default) or All users.
  • Review status counts shown above the list.
  • Admins cannot be deactivated until their role is changed to user.
  • Deactivate removes all assignments and marks the user as disabled.
  • Disabled trainers cannot log in; existing training entries are preserved.
  • Reactivate the user and reassign at least one dog to restore access.

Data review and exports

  • All Training Data supports rolling 2-week and 12-month views.
  • Use Export Displayed Records (CSV) to download the filtered admin view.
  • Use History filters for spot checks before sharing data externally.

Firebase Console: delete records not removable in app

  • The app supports deleting assignments, but some corrections require manual Firestore cleanup.
  • Before deleting, export CSV from admin view for backup/audit.
  • In Firestore Data, delete target docs from entries, dogs, or users only after checking downstream impact.
  • If deleting a dog, first remove/update related dog_assignments to prevent authorization and reporting issues.

Operational checks

  • Confirm new trainers can sign in only after assignment exists.
  • Review assignments and registered dogs weekly for drift.
  • Keep names and litter labels consistent for clean reporting.
